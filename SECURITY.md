# Security policy

## Scope

This repository is intended for public, reproducible product-development
analysis. Do not report or publish secrets in issues or pull requests.

## Sensitive material

Never commit access tokens, refresh tokens, client secrets, passwords,
participant data, private marketplace exports, course handouts, or unpublished
reports. Keep local credentials in `.env`, which is ignored by Git.

## Reporting

If a credential or personal-data exposure is suspected, revoke the credential
immediately and contact the repository owner privately through GitHub. Include
the affected commit and file path, but do not reproduce the secret.
